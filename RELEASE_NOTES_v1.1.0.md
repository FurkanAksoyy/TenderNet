# TenderNet v1.1.0

Revised replication package for “Dispersed awards, persistent ties: evidence from Türkiye’s public IT procurement”.

- Normalize explicitly foreign-currency awards using cached, hash-verified TCMB rates before deflation; retain source amounts and flag unspecified currencies.
- Correct first-future-award timing and add bounded observation windows.
- Add seven 1,000-permutation sensitivity analyses and 300 initialization-sensitivity simulations with provenance.
- Add observed-choice numerical diagnostics and collection-provenance documentation.
- Revise the manuscript, supplementary information, figures and tables around descriptive findings and explicit identification limits.
- Include a prospective human-validation protocol. Independent human classification validation has not been completed.

Validation: 50 headline checks; currency and future-horizon regression tests; observed-choice numerical diagnostics. Legacy network and full prior D simulations were not rerun in this revision. Natural persons remain pseudonymized. Code: MIT; derived data: CC BY 4.0. This release does not imply journal acceptance or submission.
